# Prior research (reference only)

A first exploration done before this repository existed. It is a rough outline of ideas and a record of what was
tried, **not** a dependency and not maintained. Nothing in `src/` imports it.

| Path | What it is |
|---|---|
| `docs/durability.md` | literature survey: who has simulated leather, what is open source, the strain screen, film-on-substrate model, flex testing, why no life prediction exists. Citations should be re-verified before publication |
| `docs/blender.md` | what Blender and add-ons can and cannot do for leather |
| `docs/wallet-reconstruction-feasibility.md` | photo-to-flat-pattern feasibility study with measured results on a synthetic photo |
| `docs/photo-intake.md`, `constraints.md`, `construction.md` | measuring from photos; wallet design rules; construction notes |
| `docs/pattern-making-tools-report.html` | survey of pattern-making tools |
| `leatherkit/` | parametric 2D pattern generator for new wallet designs (MIT, per its skill description) |
| `photo_to_pattern/reconstruct.py` | prototype: calibrated photo of a flat panel -> outline, stitch pitch, corner radius |

Useful as starting points for phase 1 (capture) and for the wear heuristics in the durability survey.
